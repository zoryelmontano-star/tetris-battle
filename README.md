# Tetris Battle Prototype

Free installable PWA prototype for a 120-second multiplayer block-battle game.

This prototype is evolving toward the broader **KO Blocks Arcade Platform** vision, with KO Blocks as the planned flagship title alongside **Mind Clash** and **Type Rush**.
